# Machine Learning

Proyectos de aprendizaje automatico con scikit-learn, cada uno con
demo en vivo.

## Proyectos

### 🗳️ Prediccion de intencion de voto (KNN)
Clasificador que predice orientacion electoral a partir de variables
socioeconomicas.
- Codigo: [proyecto-knn](./proyecto-knn)
- Demo: https://voto-knn.onrender.com/

### 🏥 Ubicacion optima de hospitales (K-Means)
Dashboard que aplica K-Means para identificar posiciones estrategicas
de centros medicos en una ciudad.
- Codigo: [hospital-placement](./hospital-placement)
- Demo: https://hospitales-rr81.onrender.com/

### 🎵 MusicIA Colombia
Sistema de recomendacion musical basado en preferencias del usuario.
- Codigo: [music-recommender](./music-recommender)
- Demo: https://recomendador-mml.onrender.com/

> Nota: las demos estan en el plan gratuito de Render, asi que si
> llevan un rato sin uso pueden tardar 30-60 segundos en cargar la
> primera vez. Es normal, solo espera.
